01 · System control

Shutdown on schedule, no surprises

Shut down, sleep, hibernate or restart: right now, in a few minutes, or on a schedule. Every action shows a countdown first, and you can cancel it.

  • When a download finishes, the PC goes idle or a program closes
  • Wake timers and repeating schedules (say, every night at 1:30)
  • Sleep and wake history
  • A command that arrives late (the PC was off) is dropped, never run by surprise
02 · Tasks & focus

Tasks in order, focus intact

A to-do list with deadlines, reminders and categories, plus a focus timer that nudges you to take a short break after every round.

  • Focus and break timer with your own durations
  • Deadline reminders
  • A weekly report of how much you got done
03 · Files & backup

Folders safe, disk light

Scheduled folder backups with verification. Restore never overwrites your current files.

  • Disk space analysis and a duplicate finder
  • Clean-up of temp and cache files, with sizes shown before deleting
  • Anything deleted goes to the Recycle Bin only
04 · Health & security

Your system's health, in plain language

Instead of cryptic event codes, it explains errors in plain words and tells you what to do.

  • Checks for disk, Windows updates and services
  • Firewall, Defender and UAC status
  • Startup-program watch and program and driver update checks
  • A redacted report with no personal data, ready to send
05 · Profiles

Change the mood of your PC in one click

Study, work, rest and night profiles run several things at once: screen brightness, volume, focus timer, break reminders and more.

  • Start automatically by time or when a game launches
  • Run history and undo
  • Export and import to share with friends
06 · Game overlay

System info over your game, your way

FPS, 1% low, GPU and CPU temperature, RAM and ping, in six layouts with your own colors and size.

  • A separate profile per game and a report after each session
  • Drag the overlay anywhere with the mouse
  • Nothing is injected into games, so anti-cheat stays happy
07 · Network & ping

See what eats your internet, and stop it

While you game, in-game protection automatically caps upload and download of other apps so your ping stays flat. When the game closes, everything is released.

  • Live ping and a stability chart
  • Per-app traffic, speed caps or blocking
  • Usage history and a monthly allowance
  • Quick DNS switcher

Frequently asked questions

Windows or my browser shows a warning. Is it dangerous?

The installer is not code-signed yet, so SmartScreen may warn you. Getting a free signing certificate is in progress; Shabpa is still new and needs more visibility before it can be approved. Click "More info", then "Run anyway", and ideally compare the file's SHA-256 with the value on this page. All the code is readable on GitHub.

Why do some antivirus programs flag it?

For per-app speed limits, Shabpa uses the open-source WinDivert driver, which some antivirus products flag because it is a network tool. If you don't need that feature, you don't have to use it.

Is my data sent anywhere?

Not by the app. Everything stays on your PC. The internet is only used when you switch something on (updates, weather, the Telegram bot, support tickets).

How do updates work?

The app fetches the new version from GitHub and only runs it if the file's SHA-256 matches the published value.

How do I uninstall it?

Like any other app, from Windows "Apps" or "Installed apps". App data stays in %AppData%\Shabpa, and you can delete it by hand if you want.

I found a bug or have an idea

Open a ticket from the app's Support page or write on GitHub. Please report security issues privately: Report a vulnerability.
