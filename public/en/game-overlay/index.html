Shabpa / Game overlay

FPS, temperatures and ping over your game, your way

Shabpa's game overlay puts system info over your game so you can see when the GPU or CPU gets hot and when frames drop. Nothing is injected into the game; it is only drawn on screen.

Download Shabpa

How do I turn on an FPS overlay?

  1. Open Shabpa and choose "Game overlay" from the side menu.
  2. Under "Display" pick a mode: off, only in game or always.
  3. Choose one of six layouts: card, horizontal bar, compact, minimal, rings or graph.
  4. Set the size (25 to 200%), background opacity (0 to 100%) and the color of each part; the preview updates instantly.

If Shabpa does not recognize your game, type its program name (for example cs2 or valorant) on the same page.

What the overlay shows

  • FPS, 1% low, GPU load and temperature, CPU load and temperature, RAM, ping and a clock (even with seconds)
  • A separate color for frame rate, GPU, CPU, RAM, NET and the clock
  • A separate profile per game and a report after each session
  • Drag the overlay anywhere with the mouse
  • Nothing is injected into the game

Frequently asked questions

Can the Shabpa overlay get me banned?

The overlay injects nothing into the game and is only drawn on screen, so it does not interfere with anti-cheat. Still, we cannot guarantee it for any specific anti-cheat; if your game is very strict, check its own rules too.

Why are some numbers empty?

Frame rate, CPU temperature and fans need administrator rights. Run Shabpa as administrator and they fill in; the other numbers work without it.
