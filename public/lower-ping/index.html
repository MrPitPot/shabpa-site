شب‌پا / کنترل اینترنت و پینگ

ببین کی اینترنتت رو می‌خوره و جلوش رو بگیر

وقتی بازی می‌کنی و یه آپدیت یا تورنت پشت صحنه خط اینترنت رو پر می‌کنه، پینگ می‌پره. شب‌پا مصرف اینترنت هر برنامه رو نشون می‌ده و می‌تونی سقف سرعتش رو بذاری یا کلاً ببندیش. «محافظ موقع بازی» هم این کار رو خودکار انجام می‌ده.

دانلود شب‌پا

چطور پینگ بازی رو پایدار نگه دارم؟

  1. از منوی کنار «پایداری پینگ» رو باز کن و پینگ زنده و نمودار پایداری رو ببین.
  2. توی لیست «چی اینترنتت رو می‌خوره» برنامه‌های پرمصرف رو پیدا کن.
  3. برای هر برنامه سقف دانلود و آپلود بذار (مگابیت یا مگابایت، هر کدوم که دوست داری) یا مسدودش کن.
  4. محافظ موقع بازی رو روشن کن تا وقتی بازی می‌کنی، سرعت بقیه‌ی برنامه‌ها خودکار محدود بشه و با بسته شدن بازی همه‌چی آزاد بشه.

برای تغییر سریع DNS هم بخش «دی‌ان‌اس» هست؛ با تست پینگ چند سرور، حتی پشت فیلترشکن.

چی تو این بخشه

  • پینگ زنده و نمودار پایداری
  • مصرف اینترنت هر برنامه، سقف سرعت یا مسدودسازی
  • محافظ موقع بازی: محدودیت خودکار بقیه‌ی برنامه‌ها تا وقتی بازی بازه
  • تاریخچه‌ی مصرف و سهمیه‌ی ماهانه
  • تغییر سریع DNS با ۱۱ سرور تازه؛ پشت فیلترشکن که همه‌ی پینگ‌ها الکی کم نشون داده می‌شه، شب‌پا گول نمی‌خوره و بهت می‌گه

سوالات پرتکرار

شب‌پا پینگ بازی رو کم می‌کنه؟

شب‌پا مسیر اینترنت تا سرور بازی رو عوض نمی‌کنه. کارش اینه که برنامه‌های دیگه (آپدیت، تورنت، مرورگر) خط اینترنتت رو اشغال نکنن تا پینگ پایدار بمونه.

چرا آنتی‌ویروس بعضی وقت‌ها هشدار می‌ده؟

برای سقف سرعت هر برنامه، شب‌پا از درایور متن‌باز WinDivert استفاده می‌کنه که چون یه ابزار شبکه‌ست، بعضی آنتی‌ویروس‌ها علامتش می‌زنن. اگه به این بخش نیاز نداری لازم نیست استفاده‌اش کنی.
